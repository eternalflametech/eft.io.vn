# Security Policy

## Supported Versions

As this repository powers the production landing site for Eternal Flame Tech, only the latest commit on the `main` branch is actively supported and maintained.

| Version / Branch | Supported          |
| ----------------- | ------------------ |
| `main`            | :white_check_mark: |
| Older releases    | :x:                |

---

## Reporting a Vulnerability

The Eternal Flame Tech team takes the security of our website, assets, and club member data very seriously.

If you discover a security vulnerability or potential exploit:

1. **Do not create a public GitHub issue.**
2. Send an email to **[eternalflametech.eft@gmail.com](mailto:eternalflametech.eft@gmail.com)** with:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept (PoC).
   - Potential impact of the issue.
3. You will receive an initial response from our team within 48 hours.
4. We will coordinate with you to verify and deploy a fix before any public disclosure.

Thank you for helping keep the Eternal Flame Tech community safe!
